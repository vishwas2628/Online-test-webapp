# 7. Use Case Diagram

The Use Case Diagram serves as a visual representation of the functional interactions between the system's users and the application itself. It clearly defines the scope of the project by mapping the two primary actors—the **Teacher** (Administrator) and the **Student**—to their respective functionalities.

In this diagram, the **Teacher** is depicted initiating critical administrative use cases such as **"Create Test"**, **"Manage Questions"**, and **"View Class Analytics"**. Conversely, the **Student** actor is shown interacting with user-centric use cases like **"Register/Login"**, **"Attempt Test"**, and **"View Result"**. This high-level blueprint ensures that all system requirements are effectively captured and assigned to the correct user roles.
